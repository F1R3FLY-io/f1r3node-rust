## Coalition structure update (2026-10-05)

The user asked for the boundary terms in the vocabulary of the coalition framework of Jamie Gabbay. The user selected semitopology as the source and `docs/semitopology/` as the directory.

### Sources

- Murdoch J. Gabbay, arXiv:2402.03253 version 3, the full book. All citations use its numbers.
- Murdoch J. Gabbay, arXiv:2303.09287 version 5, the shorter paper. Both current versions have one author.

### Findings

1. A threshold quorum rule, closed under unions, gives an intertwined semitopology (Example 2.1.4(7)). The whole member set is then a topen, and Theorem 3.2.2 gives agreement.
2. CBC Casper, Casanova, and Cordial Miners are intertwined by their threshold arithmetic. The CBC rule comes from `clique_oracle.rs`, fault tolerance `(2w - S) / S`.
3. The peer clique has an engaged subset for each transaction. Its intersection property is not yet shown. Section 17 question 5 records this gap.
4. `MembershipView.fault_bound` cannot state the four rules. Section 16 proposes an optional `CoalitionStructure` with `Threshold` and `Witness` forms.
5. Semitopology does not model Byzantine faults (Remark 23.3.1). The documents state intertwinedness as necessary, not sufficient, for safety.
6. "Coalition Logic" is also the name of a modal logic by Marc Pauly. The semitopology glossary marks the phrase as a term to avoid.
