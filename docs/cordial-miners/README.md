# Cordial Miners Documentation

This directory holds the documentation of the Cordial Miners replication medium. The
tree travels with the medium if the medium moves to its own repository. The
f1r3node-rust platform itself stays neutral about the replication medium of a
shard.

## Status

Cordial Miners is cited only. No adapter exists in this repository. Its tier is `coming_soon`.
