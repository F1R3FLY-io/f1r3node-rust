# Semitopology Documentation

This directory holds the vocabulary of semitopology, the coalition framework
of Murdoch J. (Jamie) Gabbay. The replication boundary uses it to describe the
coalition structure of a shard without a reference to one replication medium.

## Status

Semitopology is a mathematical framework, not a replication medium. No code in
this repository implements it. The
[replication boundary design](../designs/replication-boundary.md) proposes an
optional `CoalitionStructure` field in its section 16.
