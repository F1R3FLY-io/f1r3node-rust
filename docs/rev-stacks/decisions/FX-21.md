## Status

The seal format is proposed to lane C in [the FX-21 seal-format memo](../memos/FX-21-seal-format.md). No code is written until lane C agrees.

## Decisions

1. **Base.** `patch/FX-17` at 0b01b1663, the integration tip that lane C's FX-19 memo also uses.
2. **The elaborated seal is a field of `CostSignedTerm`.** It holds the kind, the origin and the per-firing limit. The signature stays, so a seal that names a bound variable still resolves at run time.
3. **The default limit is the deployment's `phloLimit`** (FX-19 §1 item 1). No new syntax is proposed for the handoff.
4. **Only user deployments are elaborated.** System, genesis and exploratory deployments are not (Decisions 81, 94, 119).
