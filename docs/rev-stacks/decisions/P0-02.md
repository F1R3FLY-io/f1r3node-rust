## D-P0-02-3 — The in-memory mirror stays consistent with LMDB on dev

- **Decision:** No extra synchronization.
- **Reason:** On dev, `insert` is the only writer of `latest_messages_index` and `invalid_blocks_index`. A8 updates the mirror in `insert`, after each LMDB write. `DagStoreMirror::load` reads both tables when the storage is constructed. The soak snapshot reads the tables but does not write them.
- **Reversible:** yes.

## D-P0-02-4 — Three tracker sections stay exclusive

- **Decision:** A8 moves three read-only equivocation reads to `read_equivocations` under the read lock. `equivocation_detector.rs:193`, `validation_dispatcher.rs:566` and `block_processor.rs:1082` keep `access_equivocations_tracker` under the write lock.
- **Reason:** The first two sites read and then write the tracker. The third site needs one consistent view of the DAG and the tracker while it prunes the buffer. Every production write to the tracker holds the write lock, so a read under the read lock sees consistent data.
- **Reversible:** yes.
