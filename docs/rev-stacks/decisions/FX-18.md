# FX-18 decisions (lane A2)

Base: `patch/FX-17` at dbc3dca9b. Plan and interface: `memos/FX-18-plan.md`.

## 1. The joiner's verification (P12-1 condition 1, P12-2 steps 2 to 4)

| Decision | Alternatives | Reason | Reversible |
|---|---|---|---|
| `v6::join::verify_join(lfb, proof, bonds)` returns the anchor root R(L) or a refusal. It checks every citer and attester (block hash and signature), finds a cited record with target L and post-root R(L), follows the records by pre-root to build the chain of roots above L, and counts each bonded attester once when its attested (block, root) pair lies on that chain. It accepts only above 2/3 of the bonded stake. | Accept attestations of L only | Attesters usually attest a later position; one matching root fixes the prefix (Q-33 section 2) | Yes |
| An attester that is not bonded refuses the proof | Ignore it | A proof that names an unbonded attester is malformed | Yes |
| A forged anchor root needs a forged record, which a single validator can sign. The quorum defeats it: honest attestations do not lie on a forged chain. | Require the citer quorum too | The attester quorum already decides | Yes |

Tests (`v6::join`): the honest proof anchors at R(L); a forged quorum is refused (one attester short, a root off the chain, one validator counted twice, a tampered sender, an unbonded attester); a forged anchor root and a missing anchor record are refused.

The bond set passed in is the one in force at L. It comes from the checkpoint and lane B's handoff chain (step 1), which is not built yet.
