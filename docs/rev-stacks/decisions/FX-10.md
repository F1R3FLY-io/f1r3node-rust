## Tests

`casper/tests/v6/pos_bond_admin_spec.rs`:

- `a_withdrawn_bond_is_released_to_its_validator_after_quarantine`:
  - Block 1: Alice bonds 1,000 through `PoS!("bond")`. The native bond and PoS `allBonds` hold 1,000.
  - Block 2: Alice withdraws. PoS no longer lists her bond, and the native bond still holds 1,000. The quarantine ends at block 4.
  - Block 3: the bond still holds 1,000.
  - Block 4: the bond is 0, and Alice's wallet gains exactly 1,000.
  - Each block replays to its post-root.
- `a_slash_moves_the_offenders_bond_to_the_compute_wallet`:
  - A genesis validator's block is recorded as invalid. A `Slash` system deploy runs PoSV6's `slash`.
  - The native bond goes to 0, PoS `allBonds` records 0, and the compute wallet gains the whole stake.
  - The slash replays to the same root.
