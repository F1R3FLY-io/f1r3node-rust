# TDD Plan: EPIC-011 — TLA+ Exhaustive Tier Red→Green

One behavior per `/tdd` invocation; `/loop /tdd` iterates until the checklist
is empty. RED/GREEN discipline for this plan is defined by the glossary's
[cap timeout](../Glossary.md#cap-timeout) vs
[violation](../Glossary.md#violation) distinction: the expected RED is a cap
timeout; a violation is never "fixed" by tuning — it triggers the B3
contingency (stop, record trace, investigate algorithm/model).

- [ ] B1 (must, tracer) — exhaustive tier dispatchable, outcomes reported distinctly
- [ ] B2 (must) — `_3v` safety configuration completes under cap
- [ ] B3 (must) — `_3v` liveness configuration completes at 3 validators under cap
- [ ] B4 (must) — nightly tier gates on the `_3v` split configurations
- [ ] B5 (should) — `MC_EquivocationDetector` liveness configuration completes under cap
- [ ] B6 (consider) — exhaustive dispatch green or accepted-unbounded documented
