# Stack-safe PDA, EPathMap, and RSpace Bag proof kernel

This development proves the algorithmic obligations shared by the generated Rust machines.

- `compile_run_equivalence` proves that an explicit post-order instruction/value-stack machine equals the mutually recursive fold for every finite typed tree and every algebra. Clone, equality, hashing, ordering, debug formatting, bincode/protobuf encoding, encoded length, clear, and teardown are instances of that theorem.
- `decoder_machine_equivalent_to_recursive_rebuild` instantiates the same machine with the tree-building algebra and proves exact reconstruction.
- `compiled_program_has_one_instruction_per_node` proves linear work and one completion instruction per node.
- `EPathMap.v` proves neutral-empty mode laws, set lattice laws, exact map-value conflict behavior, and the prefix-restriction subset law.
- `Bag.v` models an exact-key `PathMap<Multiplicity>` Bag by its total count function with zero as absence; the concrete implementation retains only its finite support. It proves commutative-monoid sum, distributive max/min lattice laws, truncated-subtraction conservation, exact-key independence from prefix relationships, canonical-delta construction, and normalized atomic apply/revert. Its live-commit bridge proves that only stored nonpersistent candidates contribute removals, selection permutations construct the same delta, play/replay publish the same exact result, and rejection cannot publish a partial update.
- `formal/verus/bag_checked_delta.rs` binds those delta equations to the executable `u64` acceptance boundary: underflow and overflow return `None`, every accepted cell has the mathematical result, and swapping a normalized successful delta restores the original count. Verus runs with `--no-cheating`.
- `formal/tlaplus/stack_safe_pda/RSpaceBagCommit.tla` exhaustively checks finite play/replay schedules for exact multiplicity, persistent/fresh exclusion, accepted-result equality, rejected-state immutability, and atomic whole-root publication.
- `formal/mcrl2/stack_safe_pda/` proves the live commit process branching-bisimilar to its atomic reference contract and independently proves that an observable partial-key publication is unreachable.
- `EPM1.v` models the actual envelope rather than an opaque suffix: canonical base-128 length fields, the length-framed ACTree03 arena, the ordered count-delimited generated-PDA value table, exact end-of-input checks, mode well-formedness, and ordinal-to-value association. It proves framing round trips, malformed/truncated/trailing rejection, ordinal uniqueness/range, and equality of generated-PDA versus recursive value bodies.
- `formal/verus/epathmap_canonical_worklist.rs` binds the canonical-key implementation shape to machine-checked Rust arithmetic: relative snapshot subranges cannot overflow or escape their enclosing region, and cursor-driven worklist validation is equivalent to recursive validation of the same result sequence. Verus runs with `--no-cheating`.
- `SpatialMatcher.v` instantiates the PDA theorem with the matcher's state-transformer algebra. It proves equivalence to recursive matching for every finite matcher tree and initial `FreeMap`, retry/disjunction and negation snapshot isolation, consistent/conflicting binding behavior, and semantic preservation of the singleton PathMap owned-zipper move optimization. Its retained-query section factors the production soundness boundary into exact-prefix and residual-query superset obligations, then proves that their conjunction cannot remove a spatial success and preserves the first spatially admissible candidate in canonical list order. The fresh-or-resting extension proves that unioning the arriving-datum candidates with terminals reached by the retained-automaton × authoritative-Bag product cannot hide a spatial success; the executable product remains responsible for establishing its prefix-terminal premise. Its generated-compiler section proves that exact, hole, and ordered RMP1 query compilation preserves every spatial success and that unsupported patterns have no compilation derivation.

The theorem kernel is schema-parametric. The generated Rust equivalence manifest binds each concrete schema surface to a theorem and an independent recursive-oracle differential. The manifest test is the coverage proof: a new generated traversal cannot remain converted without a theorem/differential row. PathMap still owns the internal ACTree03 byte grammar and parser. `EPM1.v` preserves that arena byte-for-byte and proves the surrounding framing and the association law parametrically over the executable ordinal extractor; PathMap topology parsing remains an executable-library obligation checked by the Rust differential and malformed-input suites.

The development contains no axioms, admitted goals, opaque assumptions, Verus `assume`, or external proof bodies.
